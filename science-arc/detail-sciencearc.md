# 🧪 Science Arc VR

> **스토리 기반의 초등학생용 VR 과학 교육 콘텐츠**

Science Arc는 초등학생을 대상으로,
가상 연구소를 탐험하며 과학 원리를 직접 체험하는 VR 교육 프로젝트입니다.

플레이어는 연구원이 되어 여러 과학 구역을 탐험하고,
오브젝트를 직접 잡고 배치하거나 장치를 조작하며
각 구역의 에너지 코어를 복구해 나갑니다.

과학 개념을 단순히 설명하는 방식에서 벗어나,
**VR의 공간감과 상호작용을 활용해 직접 관찰하고 조작하며 학습하는 경험**을 목표로 개발했습니다.

## 🔍 Project Overview

Science Ark는 중앙 연구소를 중심으로
네 개의 과학 구역을 선택해 체험하는 허브형 구조로 구성했습니다.

- 🔥 **불꽃색 & 빛**
  - 불꽃반응 관찰
  - 렌즈와 거울을 활용한 빛의 반사·굴절 체험

- ⚡ **전기**
  - 도체와 부도체 구분
  - 전지 직렬 연결과 전자석의 힘 변화 체험

- 🪐 **태양계**
  - 행성의 특징과 순서 학습
  - 행성 모형을 올바른 궤도에 직접 배치

- 🫀 **생명과학**
  - 구강 → 식도 → 위 → 소장 → 대장
  - 인체 내부를 이동하며 소화 과정 체험

각 구역에서 획득한 에너지 코어는 중앙 연구소의 진행 상태에 반영되며,
네 개의 코어를 모두 모으면 최종 코어 복원 단계로 이어집니다.

## 🎮 Key Features

플레이어가 단순히 콘텐츠를 감상하는 것이 아니라,
직접 행동하며 과학 원리를 체험할 수 있도록 구성했습니다.

- VR 오브젝트 Grab / Release
- 버튼 및 장치 조작
- 오브젝트 배치 기반 퍼즐
- Trigger 기반 이벤트 진행
- Portal을 통한 구역 이동
- 정답·오답에 따른 시각·음향·대사 피드백
- 주요 실험 오브젝트 분실 시 자동 복귀
- 구역별 진행 상태 저장 및 복원
- 새로운 과학 구역 확장이 가능한 모듈형 구조

## 🫀 Life Science Area

제가 담당한 생명과학 구역은
플레이어가 인체 내부로 들어가 소화 과정을 직접 체험하는 형태로 구성했습니다.

`구강`
→ `식도`
→ `위`
→ `소장`
→ `대장`

각 기관을 단순히 설명하는 대신,
플레이어가 직접 이동하고 오브젝트를 조작하면서
소화 과정과 각 기관의 역할을 자연스럽게 경험하도록 설계했습니다.

- 기관별 체험 흐름 구성
- Grab, Trigger, 버튼, Portal 등 XR 상호작용 구현
- 플레이어 행동과 미션 진행 조건 연동
- 구역별 피드백 및 진행 로직 구성
- 기관 간 이동과 전체 플레이 흐름 조정

## 🤖 AI-assisted Development

개발 과정에서는 생성형 AI를 단순한 질의 도구가 아니라
**실제 개발 워크플로우에 연결하는 방식**으로 활용했습니다.

### Blender + Codex + MCP
- Codex와 MCP를 연동한 Blender 작업
- 기존 3D 모델 수정 및 가공
- 생명과학 구역에 필요한 모델 형태 조정
- 반복적인 모델 수정 작업 자동화 및 보조

### Unity + Codex
- Unity 코드 설계 및 기능 구현 보조
- XR 상호작용 로직 수정
- 오류 원인 분석 및 디버깅
- 반복적인 기능 수정과 코드 개선

이를 통해

`3D 모델 수정`
→ `Unity 적용`
→ `기능 구현`
→ `테스트`
→ `문제 수정`

으로 이어지는 반복 개발 과정에 AI를 활용했습니다.

## 🧪 QA & Validation

개발 후반에는 팀 내 Meta Quest 장비를 활용해
**실기기 기반 QA와 최종 검수**를 담당했습니다.

- Meta Quest 실기기 빌드 및 반복 테스트
- Grab, Trigger, Portal, UI 등 주요 XR 기능 검수
- 전체 플레이 동선 및 미션 진행 조건 확인
- 오브젝트 충돌 및 위치 이탈 문제 점검
- 진행 불가능 상황 및 예외 상황 확인
- PC 환경과 실제 VR 기기 간 동작 차이 검토
- 발견된 문제 수정 후 재테스트

VR 콘텐츠는 Unity Editor에서 정상적으로 동작하더라도
실제 기기에서는 조작성이나 위치, 상호작용에 차이가 발생할 수 있어,
**구현된 기능을 실제 사용자 환경에서 반복 검증하고 다시 개발 과정에 반영했습니다.**
