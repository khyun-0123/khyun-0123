# ⚖️ TraChat

> **판결문 데이터 기반의 교통사고 형량 예측 AI 챗봇**

TraChat은 사용자가 자신의 교통사고 상황을 자연어로 입력하면,
판결문 데이터를 학습한 AI 모델을 통해 예상 형벌과 형량을 안내하는 챗봇 서비스입니다.

기존 교통사고 관련 서비스가 정형화된 질문과 일부 사고 유형 중심으로 제공된다는 점에 주목해,
사용자가 자신의 상황을 직접 입력하고 결과를 확인할 수 있는 형태로 구현했습니다.

---

## 🔍 Project Overview

프로젝트는 크게 다음 흐름으로 구성했습니다.

`판결문 수집`
→ `데이터 전처리`
→ `AI 모델 학습`
→ `서버 연동`
→ `카카오 챗봇 결과 제공`

대한민국 법원 대국민 서비스의 판결문 미리보기와
국가법령정보센터 API를 활용해 교통사고 관련 판결문을 수집했습니다.

수집한 데이터에서 사고 상황이 포함된 `이유`와
형벌 및 형량이 포함된 `주문`을 중심으로 학습 데이터를 구성했으며,
전처리 이후 약 2.8만 건의 데이터를 활용했습니다.

---

## 🧠 AI Modeling

전처리된 판결문 데이터를 기반으로
KoBERT 사전학습 모델을 활용한 전이학습을 진행했습니다.

예측 과정은 다음과 같이 구분했습니다.

- 형벌 종류 예측
- 형종별 형량 예측
- 집행유예 여부 및 기간 예측

형량 데이터는 연속형 값이기 때문에 일정 구간별 클래스로 변환해
다중분류 형태로 학습했으며,
데이터 불균형을 고려해 클래스별 가중치를 적용했습니다.

---

## 💬 Chatbot & Server

AI 모델의 예측 결과를 실제 사용자가 이용할 수 있도록
카카오 챗봇과 서버를 연결했습니다.

사용자가 사고 상황을 입력하면:

`Kakao Chatbot`
→ `Webhook`
→ `Flask Server`
→ `AI Model`
→ `Prediction Result`
→ `Kakao Chatbot`

순서로 처리됩니다.

챗봇은 사용자가 사고 상황을 구체적으로 입력할 수 있도록
질문 흐름을 제공하고,
AI 분석 결과를 형벌과 형량 형태로 다시 전달하도록 구성했습니다.

## 👨‍💻 My Role

프로젝트에서 **데이터 수집, 데이터 전처리, 챗봇 설계**를 담당했습니다.

### Data Collection
- 교통사고 관련 판결문 데이터 수집
- 법원 판결문 미리보기 데이터 Crawling
- 국가법령정보센터 API 데이터 수집 및 결합

### Data Preprocessing
- 수집 데이터 정제 및 사용 불가능 데이터 제거
- 판결문의 `이유`와 `주문`을 중심으로 학습 데이터 구조화
- 형벌 및 형량 정보 추출
- AI 학습에 사용할 수 있도록 데이터셋 구성

### Chatbot Design
- 사용자 입력 흐름 및 질문 구조 설계
- 카카오 챗봇과 서버 간 데이터 전달 구조 구성
- 사용자 입력을 AI 모델에 전달하는 Webhook 흐름 설계
- 예측 결과를 사용자에게 전달하는 응답 구조 구현

특히 **판결문 원천 데이터를 AI 학습에 사용할 수 있는 형태로 가공하는 과정부터,
모델의 결과를 실제 사용자가 이용할 수 있는 챗봇 서비스로 연결하는 과정까지**
서비스의 앞단과 뒷단을 이어주는 역할을 담당했습니다.
